# Java Memory Game

Desktop memory game developed in Java using Object-Oriented Programming (OOP) and MVC architecture.

## Features

* Multiple difficulty levels (Easy, Medium, Hard)
* Age-based thematic selection
* Dynamic card generation
* Player registration
* Score storage in MySQL database
* Full CRUD operations
* Graphical User Interface built with Swing

## Technologies Used

* Java
* MVC Architecture
* MySQL
* Swing (GUI)
* JDBC

## Architecture

The project follows the MVC design pattern:

* Model: Game logic, database connection and data management
* View: Graphical user interface and layouts
* Controller: Event handling and logic coordination
